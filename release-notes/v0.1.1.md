## What's new

- **Keyboard navigation**: ↑/↓ move through lists, ↩ opens a package, ←/→ or ⌘1–3 switch tabs, Esc goes back, plus ⌘R, ⌘, ⌘↩ and ⌘Q.
- **No more silent quit**: if macOS keeps Brewbox's icon out of the menu bar, Brewbox now shows a window that points to System Settings → Menu Bar instead of quitting without a word.
- **New bundle ID** `io.brewbox.Brewbox`. Your settings carry over automatically. If you used Launch at login, turn it on again in Settings.

## Upgrading from 0.1.0

0.1.0 can't update itself to this version because of the new bundle ID. Install it once by hand:

```bash
curl -fsSL https://raw.githubusercontent.com/richardchvalny/brewbox/main/scripts/install.sh | bash
```

or download **Brewbox.dmg** below. The build isn't notarized, so the DMG needs **Open Anyway** in System Settings → Privacy & Security the first time (the curl install doesn't).
