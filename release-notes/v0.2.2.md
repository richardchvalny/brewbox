## What's fixed

- **Brewbox 0.2.1 quit right after launch** on some Macs, before its menu bar icon appeared. It crashed while asking for permission to show notifications; it doesn't anymore.
- **The panel stays the right size**: switching from Taps, Installed or Discover back to Updates used to leave the short Updates list floating in the middle of a panel that kept the taller tab's size. The panel now shrinks to fit.

## Upgrading

If Brewbox 0.2.1 quits as soon as you open it, it can't offer this update on its own. Install it with:

```bash
curl -fsSL https://raw.githubusercontent.com/richardchvalny/brewbox/main/scripts/install.sh | bash
```

or download **Brewbox.dmg** below. The build isn't notarized, so the DMG needs **Open Anyway** in System Settings → Privacy & Security the first time (the curl install doesn't). If your Brewbox still runs, it offers this update by itself.
