## What's new

- **Trusted taps**: Homebrew 7 won't load packages from a third-party tap until you trust it, so installing from a freshly added tap used to fail. Untrusted taps are now marked **Not trusted**, and opening one offers a **Trust** button. Packages you've already trusted one by one with `brew trust --formula` keep working.
- **Paste the install line from a README**: the Taps field now takes lines like `brew tap user/tap && brew install tool`, including ones copied with a `$` prompt or a trailing `# comment`.
- **Clearer error for a repository that isn't a tap**: pasting a project's own repository (like `github.com/user/tool`) used to add an empty tap. Brewbox now removes that tap again and suggests pasting the Homebrew install line from the project's README instead.
