# Release notes

Each release needs a `vX.Y.Z.md` here, named after its tag, before the tag is pushed.
Write only what's new; the Release workflow appends `upgrading.md` and GitHub's
Full Changelog link. A release that needs its own upgrade instructions can have an
`## Upgrading` section in its notes file, which then replaces `upgrading.md`.

```markdown
## What's new

- **Feature name**: what it does for the person using Brewbox.
```
