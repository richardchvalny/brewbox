## What's new

- **Taps tab** (⌘4): install packages from outside Homebrew's own repositories. Add a tap by typing `user/repo` or pasting its repository URL (GitHub, GitLab or `git@…`). You can also paste a whole command like `brew install --cask user/tap/package`, and Brewbox adds its tap.
- **Browse a tap**: open a tap to see its formulae and casks, install them in one click, jump to its repository, or remove the tap. Homebrew won't remove a tap while packages from it are installed, so uninstall those first.
- **Tapped packages everywhere**: packages from your taps show up in Discover search, labeled with their tap, and get updates and automatic updates like any other package.
- **Safer installs from taps**: Brewbox installs tapped packages by their full `user/repo/name`, so Homebrew can't pick a same-named package from its own repositories instead.

## Upgrading

Brewbox 0.1.1 offers this update on its own. To get it right away, run:

```bash
curl -fsSL https://raw.githubusercontent.com/richardchvalny/brewbox/main/scripts/install.sh | bash
```

or download **Brewbox.dmg** below. The build isn't notarized, so the DMG needs **Open Anyway** in System Settings → Privacy & Security the first time (the curl install doesn't).
